# Minecraft 26.3 升级验证

验证日期：2026-09-24。环境：Windows、Java 25.0.2、Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.161.0+26.3。

## 26.3 升级基线（2026-09-24）

- 更新依赖、模组元数据和 README，模组版本仍为 1.4。
- 使用游戏自带 SDL 异步文件对话框替代不再随游戏提供的 TinyFileDialogs；保留 AWT 后备方式。
- 将配方解锁进度条件的 `recipe` 字段迁移为 26.3 的 `recipes` 字段，配方和解锁条件不变。
- 未修改上传权限、网络协议、配置、存储、音频转换、播放参数或 Mixin 逻辑。

## 服务端转换改动（2026-09-25）

客户端现在上传原始音频，服务端在后台使用配置的 ffmpeg 转成 Ogg Vorbis。客户端只读取和分块发送源文件，不再调用或查找 ffmpeg；ffmpegPath 由服务端读取。上传权限、持有唱片检查、曲库容量限制、SHA-1 校验、转换参数和唱片绑定规则保持原样。

因此，下表中的“缺少 ffmpeg”和“非 OP 上传及重新导入”结果只验证 2026-09-24 的升级基线，不代表服务端转换版本的实测结果。当前版本的构建和静态检查结果见本次交付说明；新的联机转换流程仍需在游戏内验证。

## 已验证

| 场景 | 结果 |
| --- | --- |
| `gradlew.bat build` | 成功；客户端及公共代码均编译通过。项目当前没有自动化测试源，不能将构建成功等同于单元测试通过。 |
| JAR 内容 | 包含客户端和服务端类、SDL 对话框实现、正确版本声明及迁移后的进度 JSON。 |
| 独立服务端启动 | 在隔离目录中成功加载注册表、配方和世界，进入 `Done` 状态。 |
| 两个客户端联机 | 均成功连接仅监听本机的测试服务端；测试玩家没有 OP 权限。 |
| Mixin | 运行日志确认五个 Mixin 均应用于目标类，无注入失败。 |
| SDL 文件选择器 | 系统窗口正常打开，显示原有音乐／视频筛选；取消后恢复待选状态，可再次打开。 |
| 非 OP 上传及重新导入 | 同一张唱片连续导入两首曲目成功，服务端完成保存及绑定。 |
| 中文路径 | `中文 测试, song.ogg` 成功选择、转换及上传，唱片保留中文、空格和逗号标题。 |
| 缺少 ffmpeg | 将测试配置指向不存在的程序后，显示既有缺失提示；恢复路径后无需重启即可导入。 |
| 多人文件同步 | 第二个客户端从空曲库自动下载两首曲目，SHA-256 均与服务端一致。 |
| 唱片机 | 已绑定唱片成功插入；服务端记录播放计时及原有曲目组件；右键弹出后唱片机记录清空。未对实际声音输出进行人工听音确认。 |
| 旧配置和曲库副本 | 旧配置可加载；旧 Ogg 文件哈希保持不变，生成资源包采用当前游戏格式。 |
| 配方注册 | 服务端可通过 `recipe give` 解锁自定义唱片配方。 |

测试使用独立目录和新世界，没有升级原有存档。测试数据与原始运行日志保留在本地忽略目录 `build/upgrade-check/`。
