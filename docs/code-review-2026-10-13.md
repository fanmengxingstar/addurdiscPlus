# 模组代码审查与修复

审查日期：2026-10-13。基线：`895a9bd`，Minecraft 26.3 / Fabric API 0.161.0 / Java 25。
修复分支：`codex/review-multiplayer-sync`。

## 约束

上传权限继续完全开放，没有增加 OP、白名单或权限等级检查。保留原有唱片持有检查、服务端容量限制、转换参数及分块格式。旧 `PlaySong` 通道保留；播放进度和可靠停止使用两个新增通道，并根据客户端支持情况选择发送。旧客户端在同维度使用原版停止事件兼容，完整进度同步需要两端都更新。

## 已修复的问题

| 问题与根因 | 修复 |
| --- | --- |
| 同步调用完整 `SoundManager.reload`，会销毁正在播放的全部声音通道。 | 自定义声音实例直接提供流式音频，不重建声音引擎。停止只针对对应唱片机；异步打开、解码与关闭可取消。 |
| 播放只广播一次，晚加入、接近播放中的唱片机和存档恢复均缺少通知。播放 AABB 与原版停止球形范围也不一致。 | 每秒检查该唱片机的监听者差集，仅向新进入范围的玩家发送当前进度；离开、弹出、结束及卸载时向已通知者发送停止。状态包含维度。 |
| 下载完成后才开始播放，会落后于服务器；停止后未完成的下载也可能迟播。 | 保存接收通知的时间，后台按已播放进度跳过解码样本；停止和换维度清理等待项。跳转位于解码包边界，存在少量时间误差。 |
| 客户端网络处理器同步进行文件哈希、曲库检查及写盘，冷缓存和大曲目会占用客户端线程。 | 使用独立后台同步线程；连接世代使断线后的检查、保存完成与通知失效。保存阶段仍保留下载占位，避免重复排队。 |
| 跨服务器同名本地文件可能在验证前播放。 | 只有当前连接已验证的曲目进入可播放集合。 |
| 客户端用自己的 `maxSongMegabytes` 服务端配置拒收远程服务器合法曲目，两端配置不同便会静音。 | 服务端继续执行入库配额；客户端按协议 128 MiB 硬上限接收，仍限制下载缓冲分配。 |
| 顺序下载小曲目超过每秒八次被直接丢弃，客户端无端等待十五秒；令牌桶空闲约九分钟后乘法溢出。 | 保留限速，以窗口内等待代替丢弃；长空闲直接补满令牌，避免溢出。 |
| 下载工作线程以 UUID 清理状态，可能删除重连或下一次下载的占位；服务器停顿时可能积累整首曲目的回调。 | 以连接对象和每次传输对象共同标识状态；末块发送前释放该传输，旧 finally 只能清理自身；每个下载最多等待一个待发送块。 |
| 上传预算和临时文件依赖已停止服务器的回调清理；未完成上传可无限占用预算；排队转换取消后不运行 finally。 | 状态归属各服务器，预算以原子操作且仅释放一次；停服／断线取消转换并删除临时文件；接收阶段三十秒无进展则回收。 |
| 旧界面的异步文件准备和上传结果可能作用于新界面，甚至发送到另一服务器。 | 在界面创建／发起上传时捕获连接与监听者；结果只通知原监听者，过期连接的准备结果不发送。 |
| 合法长名称重名、超过九百九十九个重名会导致命名失败，后台异常可能不回应客户端。 | 为数字后缀预留长度，按配额寻找空名；后台运行时异常转换成明确的失败结果。 |
| 转换先读入全部输出再检查大小，压缩输入可产生超限输出。 | ffmpeg 使用 `-fs` 限制临时输出，并在读入内存前检查大小；超限截断结果不会当作成功。ffmpeg 允许输出略超 `-fs`，因此仍需要最终大小检查。 |
| 漏斗可绕过玩家交互检查插入空白唱片；铁砧复制分支覆盖了输入的新名称。 | 拦截漏斗空白唱片入口，空白自定义唱片不解析为占位歌曲；复制时应用原版命名规则。 |
| Windows 非法文件夹名和驱动器相对路径通过配置校验，可能启动崩溃或指向意外位置。 | 使用平台 `Path` 校验目录名，并拒绝带根的相对父路径；合法中文和空格路径保留。 |

## 保留的正确行为

原版唱片逻辑、复制时保留右侧源唱片、经验消耗、配方、上传权限、已有歌曲组件、播放器音量和衰减参数均保留。公共代码继续使用独立服务端源集编译，没有引入客户端类依赖。

## 回归检查

脚本编译并执行实际生产方法，使用少量替身隔离游戏初始化、连接及文件系统边界；生成物只写入 `build/review-check`。声音和客户端网络脚本支持 `--baseline`，玩法脚本支持 `-BaselineRef HEAD` 复现原提交的失败。替身检查不能代替真实 Mixin 注入和人工听音。

```powershell
.\gradlew.bat --offline build
.\scripts\review-network.ps1
python scripts/review-client-network.py
python scripts/review-sounds.py
.\scripts\review-store-audio.ps1
.\scripts\review-gameplay.ps1
.\scripts\review-server.ps1
```

构建成功不等于 Gradle 单元测试通过：本项目没有 JUnit 测试源，上述专项回归通过各自脚本执行。FFmpeg 专项需要本机可执行文件；脚本使用隔离曲库，不修改现有音乐或存档。
